# 🚀 UniCompare – College Discovery & Decision Platform

**UniCompare** is a production-grade MERN stack application designed to help users **discover, compare, and shortlist colleges** efficiently.  
It focuses on **decision-making**, not just browsing, through comparison tools, scoring systems, and smart tagging.

🔗 **Live App:** https://unicompare-1.onrender.com/

---

## ✨ Features

### 🔹 Core Functionality
- **Discover Colleges**  
  Browse a list of colleges with key details like location, fees, and ratings.

- **Search & Filters**  
  Search by college name and filter by:
  - Location  
  - Maximum fees  

- **Detailed College Views**  
  Dedicated pages showing:
  - Courses offered  
  - Placement statistics  
  - Average package  
  - Reviews (mock)

- **⚖️ Compare Colleges (Key Feature)**  
  Select up to 3 colleges and compare side-by-side:
  - Fees  
  - Placement %  
  - Rating  
  - Location  

  Includes dynamic highlights:
  - Most Affordable  
  - Highest Placement Rate  
  - Best Overall Score  

- **🔐 User Authentication**  
  Secure signup/login using JWT

- **📌 Saved Dashboard**  
  Users can bookmark and manage saved colleges

---

### 🌟 Standout Features
- **📊 Decision Score Algorithm**  
  Each college gets a score out of 100 based on:
  - Placement percentage  
  - Rating  
  - Fee optimization  

- **🏷️ Smart Tags**  
  Automatic tags such as:
  - Best ROI  
  - Top Placement  
  - Budget Friendly
